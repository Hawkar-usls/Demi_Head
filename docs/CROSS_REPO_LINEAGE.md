# Cross-Repository Lineage

This record distinguishes reusable JANUS mechanisms from copied implementation and transferred authority.

DemiHead is a **composition head**, not a license to merge every sibling repository into one executable. Reuse is admitted only when the imported idea has an explicit role, a preserved boundary, and a testable local contract.

```text
REPOSITORY_PRESENCE != AUTHORSHIP
REPOSITORY_PRESENCE != MATURITY
METHOD_REUSE != AUTHORITY_TRANSFER
DOMAIN_EVIDENCE != CROSS_DOMAIN_EVIDENCE
```

## KETO portfolio audit rule

KETO may discover a mechanism in another repository and propose it for use, but that proposal has zero external authority until admitted locally.

```text
DISCOVER
-> CLASSIFY
-> QUARANTINE DOMAIN-SPECIFIC CLAIMS
-> DEFINE LOCAL CONTRACT
-> ADD NEGATIVE TESTS
-> ADMIT OR REJECT
```

A useful example is the swarm rule "no fake sensors." In DemiHead it becomes a civic information invariant:

```text
NO SOURCE != FALSE
STALE SOURCE != CURRENT SOURCE
CENTRAL BACKEND DOWN != INVENT AN ANSWER
```

The original firmware code does not need to be copied for that invariant to be useful.

## Patterns intentionally excluded

- covert mass persuasion;
- autonomous astroturf or self-spawning public identities;
- bypass of platform permissions, rate limits or terms;
- process injection, memory scraping or hidden control;
- psychographic political targeting;
- automatic conversion of state statements into objective truth;
- speculative `tachyon`, precognition, consciousness or metaphysical mechanisms;
- historical magic constants without a frozen measurement rationale;
- copying complete legacy modules before inputs, side effects and licenses are audited;
- treating internal Face consensus as external corroboration.

## Source-code import policy

Future code reuse requires a separate record naming:

- source repository and exact commit;
- original license and attribution;
- files/functions imported;
- behavior retained and behavior removed;
- secrets/network/side-effect review;
- tests added for DemiHead's boundary;
- why reuse is preferable to a fresh small implementation.

Until such a record exists, sibling repositories are methodological references only.
