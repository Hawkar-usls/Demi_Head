# Cross-Repository Lineage

This record distinguishes reusable Janus methods from copied implementation. At the foundation stage, DemiHead adopts design patterns only; no sibling source file has been imported.

| Repository | Pattern adopted | Boundary retained |
| --- | --- | --- |
| `Janus` | public maturity vocabulary, `PROJECT_STATUS.json`, claim discipline | metadata structure is not evidence of runtime quality |
| `janus-io-public` | observer-first measurement, explicit work accounting, null-result preservation | no SHA-256 weakness, energy saving, or profitability claim is transferred |
| `janus-distributed-ai-swarm` | protocol invariants, heartbeat/freshness states, observer pressure limits | embedded node semantics are not copied into desktop process telemetry |
| `AIFC` | fail-closed admission, provenance, canonical machine objects | no independent-future or retrocausal research claim is part of DemiHead |
| `Janus-Fundamentum` | preserve failed routes, distinguish finite tests from broad conclusions | mathematical evidence status is not transferred to systems engineering |
| `Janus_Genesis` | portable JSON state and explicit authority boundaries | fictional agency and world-state semantics are excluded |
| `Janus-Demiurge` | historical resource-monitoring and adaptive-loop lessons | legacy code and speculative terminology are not current authority |
| `HRain` | optional future graph projection for inspectable lineage | a graph visualization is not a cognitive or BCI claim |
| `janus-meta-registry` | structured archival reports and provenance | registry presence does not promote a hypothesis into a result |

```text
MEASURE_BEFORE_OPTIMIZING
UNKNOWN_IS_NOT_ZERO
STALE_IS_NOT_ACTIONABLE
OBSERVER_COST_IS_PART_OF_THE_RESULT
NEGATIVE_RESULTS_ARE_FIRST_CLASS
SCHEMA_VALID_IS_NOT_TRUE
HASH_IS_LINEAGE_NOT_TRUTH
FACE_EFFECT_SCOPE_MUST_BE_EXPLICIT
```

## Patterns intentionally excluded

- claims of literal zero overhead;
- process injection, memory scraping, or hidden control;
- reinterpretation of application payloads as entropy without an explicit contract;
- speculative `tachyon`, precognition, consciousness, or metaphysical mechanisms;
- historical magic constants without a frozen measurement rationale;
- copying complete legacy modules before their inputs, side effects, and licenses are audited;
- treating a hash stream as useful solely because it appears random.

## Import policy

Future source reuse requires a separate record naming:

- source repository and exact commit;
- original license and attribution;
- files or functions imported;
- behavior retained and behavior removed;
- tests added for DemiHead's boundary;
- reason reuse is preferable to a fresh implementation.

Until such a record exists, sibling repositories are methodological references only.
