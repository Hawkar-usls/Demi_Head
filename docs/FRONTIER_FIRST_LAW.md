# JANUS Frontier-First Law

Canonical rule:

> If you are working on something, first check whether someone has already done it before you.

The purpose is not novelty policing. The purpose is to avoid spending time rebuilding solved work and to continue from the best verified existing frontier.

```text
SEARCH BEFORE CLAIM
SEARCH BEFORE BUILD
REUSE SOLVED
CONTINUE FROM FRONTIER
```

## Decision path

```text
TASK / IDEA
   |
   v
FREEZE CURRENT INTENT
   |
   +--> REPOSITORY AWARENESS + KETO  (internal prior work)
   |
   +--> TOPA + SPIDER                 (external prior work)
   |
   v
VERIFY RELEVANCE / PROVENANCE / LIMITS
   |
   +--> nothing relevant found
   |       -> start from first principles
   |
   +--> prior work found but unverified
   |       -> verify before reuse
   |
   +--> verified frontier with open gaps
   |       -> reuse solved components
   |       -> attack open gaps
   |
   +--> verified frontier with no relevant open gap
           -> do not rebuild solved work
           -> stop, reframe, or seek a higher-order extension
```

## Frontier definition

A frontier is not merely the newest or most popular result. A JANUS frontier must be relevant to the current intent and sufficiently verified for the intended reuse.

```text
SEARCH_RESULT != FRONTIER
POPULARITY != VALIDITY
LATEST != BEST
UNVERIFIED != REUSABLE
```

The selected starting point is therefore:

```text
STARTING_POINT = BEST_VERIFIED_RELEVANT_EXISTING_FRONTIER
```

not zero.

## Reuse boundary

Reusing solved knowledge is encouraged. Copying code, text, data, designs, or other protected artifacts still requires their applicable attribution, license, permission, and compatibility conditions.

```text
REUSE_SOLVED != IGNORE_LICENSE
IDEA_SIMILARITY != COPY_PERMISSION
PRIOR_EXISTENCE != PRIOR_KNOWLEDGE
SIMILARITY != PLAGIARISM
```

## Relationship to Convergence

Frontier-First answers: **where should we start?**

Convergence answers: **what becomes possible when our path meets an existing one?**

```text
FRONTIER-FIRST
    -> find and verify what is already solved
    -> expose remaining gap
CONVERGENCE
    -> align structures
    -> preserve unique parts
    -> search for interaction delta / THIRD_THING
FUNDAMENTUM
    -> try to falsify the extension
META REGISTRY
    -> preserve lineage and receipts
```

## Epistemic invariants

```text
SILENCE != NEGATIVE EVIDENCE
FOUND_PRIOR_WORK != STOP
UNVERIFIED_WORK != FRONTIER
SEARCH_RESULT_COUNT != EVIDENCE_QUALITY
FRONTIER_SELECTION != AUTHORITY
```

This law changes starting-point selection, not external authority.
