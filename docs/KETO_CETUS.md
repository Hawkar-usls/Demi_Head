# KETO / CETUS Naming Note

The project uses Greek-mythology vocabulary as a memorable engineering naming layer. Mythology does not grant technical authority and is not evidence for system behavior.

## Historical distinction

`Keto / Ceto (Kētō)` is the ancient sea deity associated with the dangers and monsters of the sea. In Hesiod's *Theogony*, Ceto and Phorcys are parents of several monstrous figures including the Graiae, Gorgons, and the serpent guarding the golden apples.

The sea creature in the Andromeda/Perseus story belongs to the `ketos` / sea-monster tradition and is commonly represented as `Cetus` in later naming. The project therefore avoids treating **Ceto/Keto** and **Cetus** as one mythic individual.

## Engineering translation

### KETO

The parent audit/composition layer.

KETO may:

- inspect the JANUS ecosystem for reusable mechanisms;
- classify mechanisms by role;
- quarantine domain-specific claims;
- propose bounded local contracts;
- request tests and review;
- compose admitted capabilities.

KETO may **not** convert discovery into ambient authority.

```text
KETO_DISCOVERS_CAPABILITIES
KETO_DOES_NOT_INHERIT_AUTHORITY
```

### CETUS

A bounded case presented to the system.

Examples:

- one claim;
- one suspicious banner;
- one source cluster;
- one repeated narrative;
- one incident needing provenance analysis.

A CETUS case has a beginning, evidence graph, terminal state, and release-control path.

```text
CETUS != USER
CETUS != ENEMY
CETUS = BOUNDED_INFORMATION_CASE
```

This prevents an information problem from being converted into a psychological label for the person who submitted it.

### KRAKEN

`KRAKEN_MODE` is retained as a humorous operator alias for a deep ecosystem sweep. It has no separate authority semantics.

```text
KRAKEN_MODE = KETO_CETUS_DEEP_SWEEP_ALIAS
```

## Post-ironic safety rule

Humor is a presentation layer only.

It must never change:

- claim status;
- urgency;
- uncertainty;
- source roots;
- user rights;
- required safety action.

Humor is disabled by default for emergency, child, self-harm crisis, trauma/bereavement, high-stakes medical, and high-stakes legal contexts.
