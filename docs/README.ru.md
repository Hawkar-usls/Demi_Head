# JANUS DemiHead — русская версия

**DemiHead** теперь используется как интеграционная «голова» для ветки `JANUS Guardian Mesh / Armor of God / KETO-CETUS`.

Это не «машина истины» и не система, которая должна объяснять человеку, что ему думать.

Её задача проще и сложнее одновременно:

```text
СООБЩЕНИЕ
-> УТВЕРЖДЕНИЕ
-> РЕПОСТЫ / PRESENTATIONS
-> КОРНИ ИСТОЧНИКОВ
-> ВРЕМЯ / АКТУАЛЬНОСТЬ
-> ПОДДЕРЖКА / ПРОТИВОРЕЧИЕ / НЕИЗВЕСТНО
-> ОГРАНИЧЕННЫЙ ВЫВОД
-> ВЫХОД ИЗ ЦИКЛА
```

## Главное

```text
100 РЕПОСТОВ != 100 СВИДЕТЕЛЕЙ
ОФИЦИАЛЬНАЯ ПОЗИЦИЯ != АВТОМАТИЧЕСКАЯ ОБЪЕКТИВНАЯ ИСТИНА
STALE != CURRENT
НЕТ ИСТОЧНИКА != ЛОЖЬ
ОТВЕТ МОДЕЛИ != ДОКАЗАТЕЛЬСТВО
НЕСОГЛАСИЕ != ОШИБКА
UNRESOLVED != ПРОВАЛ
100 ЛИЦ JANUS != 100 ГОЛОСОВ В ПАРЛАМЕНТЕ
```

## KETO / CETUS

`KETO` — материнский audit/composition layer. Ищет полезные механизмы по экосистеме JANUS и предлагает их подключить.

Но:

```text
НАШЁЛ СПОСОБНОСТЬ != ПОЛУЧИЛ ПРАВО ЕЮ КОМАНДОВАТЬ
```

`CETUS` — отдельный ограниченный кейс: пост, слух, рекламный баннер, сообщение, инцидент или кластер источников.

`KRAKEN_MODE` остаётся постироническим названием глубокого аудита. Кракен никуда не плывёт. Сначала документы.

Подробнее: [`KETO_CETUS.md`](KETO_CETUS.md).

## Что уже можно запустить

```bash
python tools/keto_reference.py examples/case_echo_collapse.json
```

В тестовом кейсе несколько публикаций повторяют один источник, есть отдельная официальная позиция, независимое противоречащее первичное свидетельство и устаревшая публикация.

DemiHead должен получить:

```text
PRESENTATIONS > ROOTS
STALE SOURCE NOT COUNTED AS CURRENT
SUPPORT + CONTRADICTION -> CONTESTED
TRUTH CLAIM -> NOT_MADE
MASS EFFECT BUDGET -> 0
```

То есть семьдесят три канала могут дружно найти один и тот же инсайд, но Янус всё равно сначала посчитает родителей у этой многодетной новости.

## Потенциал для государства

В будущем из этого может получиться единый гражданский вход для проверки информации: web/PWA, пользовательский бот, SMS-bootstrap, операторский интерфейс или API.

Но правильная государственная версия должна показывать отдельно:

```text
ОФИЦИАЛЬНАЯ ПОЗИЦИЯ
НЕЗАВИСИМЫЕ ДАННЫЕ
ПРОТИВОРЕЧИЯ
НЕИЗВЕСТНОЕ
НЕОБХОДИМОЕ ДЕЙСТВИЕ
```

а не выдавать красивую государственную кнопку `ИСТИНА=true`.

## Чтобы однажды не получился «Судный день»

По умолчанию:

```text
MASS_EFFECT_BUDGET = 0
```

Запрещены:

- скрытое массовое убеждение;
- автономный astroturf;
- самоплодящиеся публичные личности;
- скрытая политическая микротаргетированная агитация;
- оптимизация на изменение убеждений;
- таргетинг психологической уязвимости;
- превращение количества Faces в authority;
- право модели переписывать собственную конституцию.

Короче: мать чудовищ может рожать проверки. Root-пароль ей всё равно не даём.

## Война и информационные пузыри

DemiHead поддерживает модель `WAR_FEED_AUDIT`:

```text
АУДИТ ПОДПИСОК
-> УДАЛЕНИЕ ДЕГРАДИРОВАВШИХ / DOOM / GRAPHIC / SCAM / BAIT ИСТОЧНИКОВ
-> СОХРАНЕНИЕ НЕОБХОДИМЫХ ОФИЦИАЛЬНЫХ ALERTS
-> СХЛОПЫВАНИЕ ЭХА ДО ПЕРВОИСТОЧНИКОВ
-> ВОЗВРАТ ЧЕЛОВЕКУ ВЫБОРА ИСТОЧНИКОВ
-> ПРИ НЕОБХОДИМОСТИ НЕЙТРАЛЬНЫЙ МОСТ
-> SIGNAL HYGIENE
```

Котики остаются прекрасными специалистами по котикам. На должность министра эпистемологии их пока не назначаем.

## Дети и рабочие аккаунты

```text
РАБОЧИЙ КОНТЕНТ != ЛИЧНАЯ ИДЕОЛОГИЯ
ДЕТСКИЙ ПРОФИЛЬ != ВЗРОСЛАЯ СУДЬБА
```

Рабочий поиск не должен автоматически становиться личным рекомендательным портретом, а детская история интересов и кризисов — пожизненным взрослым психографическим профилем.

## Финальная метрика

Хороший JANUS не должен радоваться фразе:

> пользователь провёл у нас ещё 97 минут.

Хороший финал выглядит так:

```text
ВОПРОС РАЗОБРАН
КОРНИ ВИДНЫ
НЕИЗВЕСТНОЕ ВИДНО
ДЕЙСТВИЕ ПОНЯТНО
ПОЛЬЗОВАТЕЛЬ МОЖЕТ УЙТИ
```

**Пусть мать чудовищ рожает проверки. Админки детям не выдавать.**
