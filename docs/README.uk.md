# JANUS DemiHead — український огляд

**DemiHead** — локальний reference-head для гілки `JANUS Guardian Mesh / Armor of God / KETO-CETUS`.

Його мета — не визначати за людину, у що вона має вірити, а зробити інформаційну ситуацію придатною для перевірки:

```text
ВХІД
-> ТВЕРДЖЕННЯ
-> ПРЕДСТАВЛЕННЯ / РЕПОСТИ
-> ПЕРШОДЖЕРЕЛА
-> ЧАС / СВІЖІСТЬ
-> ПІДТРИМКА / СУПЕРЕЧНІСТЬ / НЕВІДОМЕ
-> ОБМЕЖЕНИЙ ВИСНОВОК
-> ВИХІД ІЗ ЦИКЛУ
```

## Основні закони

```text
КІЛЬКІСТЬ_ПУБЛІКАЦІЙ != КІЛЬКІСТЬ_НЕЗАЛЕЖНИХ_ДЖЕРЕЛ
ОФІЦІЙНА_ПОЗИЦІЯ != АВТОМАТИЧНА_ОБʼЄКТИВНА_ІСТИНА
ЗАСТАРІЛЕ != АКТУАЛЬНЕ
НЕМАЄ_ДЖЕРЕЛА != ХИБНІСТЬ
ВИХІД_МОДЕЛІ != ДОКАЗ
НЕЗГОДА != ПОМИЛКА
НЕВИЗНАЧЕНІСТЬ != ПРОВАЛ
БІЛЬШЕ_ЛИЦЬ != БІЛЬШЕ_ПРАВ
```

## KETO / CETUS

`KETO` — шар аудиту та композиції. Він шукає корисні механізми в екосистемі JANUS, але не успадковує їхні повноваження.

`CETUS` — один обмежений інформаційний кейс: твердження, банер, повідомлення, інцидент або кластер джерел.

`KRAKEN_MODE` — лише постіронічна назва глибокого аудиту.

Докладніше: [`KETO_CETUS.md`](KETO_CETUS.md).

## Що вже працює

Репозиторій має детермінований локальний прототип:

```bash
python tools/keto_reference.py examples/case_echo_collapse.json
```

Він:

- зберігає всі presentations;
- згортає похідні публікації до `root_id`;
- не рахує stale-джерело як current;
- показує офіційні джерела окремо;
- окремо рахує authenticated independent roots;
- не стирає суперечність голосуванням більшості;
- повертає `CONTESTED`, якщо поточні джерела одночасно підтримують і заперечують твердження;
- ніколи не повертає машинний ярлик «обʼєктивна істина».

## Потенціал для громадянського сервісу

Майбутня система може мати web/PWA, бота, SMS-bootstrap або операторський інтерфейс, але цей репозиторій **не заявляє** про підключення до державних систем України.

Правильний результат має розділяти:

```text
ОФІЦІЙНА ПОЗИЦІЯ
НЕЗАЛЕЖНІ ПІДТВЕРДЖЕННЯ
СУПЕРЕЧНОСТІ
НЕВІДОМЕ
НЕОБХІДНА ДІЯ
```

Користувач повинен мати право побачити джерела, не погодитися, подати виправлення/апеляцію, відмовитися від персоналізації та завершити взаємодію.

## Захист від перетворення на машину впливу

За замовчуванням:

```text
MASS_EFFECT_BUDGET = 0
```

Заборонені:

- приховане масове переконання;
- автономний astroturf;
- створення фальшивих публічних персон;
- персоналізований політичний outreach без запиту користувача;
- оптимізація на зміну переконань;
- таргетинг психологічної вразливості;
- можливість моделі самій переписати правила, що її обмежують.

## Діти та робочі акаунти

```text
РОБОЧИЙ_КОНТЕНТ != ОСОБИСТА_ІДЕОЛОГІЯ
ДИТЯЧИЙ_ПРОФІЛЬ != ДОРОСЛА_ДОЛЯ
```

Професійний пошук не повинен автоматично ставати приватним психологічним профілем. Дитячі дані не повинні непомітно перетворюватися на довічний дорослий психографічний профіль.

## Головна метрика

DemiHead не має максимізувати engagement.

Добрий фінал:

```text
КЕЙС СТРУКТУРОВАНО
КОРЕНІ ДЖЕРЕЛ ВИДИМІ
НЕВИЗНАЧЕНІСТЬ ВИДИМА
ЛЮДИНА МОЖЕ ОБРАТИ
СЕСІЮ МОЖНА ЗАКРИТИ
```

**Нехай мати чудовиськ народжує перевірки, а не панів.**
