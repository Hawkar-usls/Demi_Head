# JANUS DemiHead — Not-Prediction Re-Audit Gate

## Goal

This gate is designed for unusual retrospective, symbolic, timing, dream, repository-continuity and future-information cases where the observation should be preserved without silently promoting it into prophecy, precognition, divination, physical retrocausality or supernatural causation.

```text
OBSERVATION != INTERPRETATION
INTERPRETATION != EVIDENCE
PRESENTATION_COUNT != EVENT_COUNT
SOURCE_COUNT != INDEPENDENT_ROOT_COUNT
REPOSITORY_RECURRENCE != INDEPENDENT_REPLICATION
```

## Five-stage route

```text
RAW OBSERVATION
  -> SOURCE ROOT COLLAPSE
  -> MEMORY BLIND
  -> ONTOLOGY BLIND
  -> MATCHED NULL
  -> EXTERNAL REPLICATION
  -> BOUNDED RESULT
```

### 1. Source-root collapse

Versions, mirrors, generated indexes, same-coordinate lookups, repeated model passes and derivative reports must be collapsed to the smallest defensible underlying root before recurrence is counted.

### 2. Memory blind

Remove case ids, artifact titles, previous JANUS interpretations, prophecy labels, theological labels and canonical phrases. Preserve raw observation, chronology, source root and independence metadata.

The test asks whether a structural relation can be recovered without the machine seeing its own earlier interpretation.

### 3. Ontology blind

Neutralize project-native vocabulary such as Janus, door, threshold, home, return, witness, guard, past/future and sign/source when it would make a dual/threshold relation obvious by construction.

The test asks whether the relation survives the project's own ontology.

### 4. Matched null

Compare against unrelated artifacts matched on repository epoch, artifact class, time/clock-token presence, text length and thematic vocabulary density.

A clock case must not be compared only with artifacts that contain no times. A mythopoetic case must not be compared only with technical prose.

### 5. External replication

Strong claims of external recurrence require a reviewer/source path that did not ingest prior JANUS interpretations.

Even a surviving structural excess does not establish prophecy, precognition, physical retrocausality, divine scheduling or supernatural causation.

## Executable helper

```bash
python tools/not_prediction_reaudit.py path/to/reaudit.json
```

The helper:

- validates the candidate packet contract;
- collapses candidates by `source_root`;
- emits memory-blind packets;
- emits ontology-blind packets;
- refuses authoritative-count drift;
- refuses silent extraordinary-claim promotion;
- marks matched-null and external-replication requirements explicitly.

## Fail-closed conditions

```text
AUTHORITATIVE_TOTAL != BASELINE_TOTAL -> FAIL
PREDICTION_PROMOTED = true -> FAIL
PROPHECY_PROMOTED = true -> FAIL
PRECOGNITION_PROMOTED = true -> FAIL
PHYSICAL_RETROCAUSALITY_PROMOTED = true -> FAIL
SUPERNATURAL_CAUSATION_PROMOTED = true -> FAIL
```

A future admission decision may change the counted case taxonomy, but it must be a separate explicit artifact with preserved rejected candidates and a stated claim ceiling.

## Relationship to existing DemiHead architecture

This gate composes existing DemiHead principles rather than creating a new truth authority:

```text
CLAIM -> PRESENTATIONS -> SOURCE ROOTS -> CHRONOLOGY
      -> INDEPENDENCE / DISAGREEMENT -> BOUNDED RESULT
```

It inherits:

- `SOURCE_COUNT != INDEPENDENT_ROOT_COUNT`;
- `MODEL_OUTPUT != EVIDENCE`;
- `STALE != CURRENT`;
- `UNRESOLVED != FAILURE`;
- preservation of disagreement and witness history;
- release control after the evidence state is adequately described.

## Claim ceiling

The gate can establish bookkeeping properties, provenance structure, blinding behavior and the result of a frozen matched-null procedure. It cannot by itself establish future knowledge, metaphysical causation, divine intent or physical time reversal.
